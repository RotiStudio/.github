# RotiStudio

**Lightweight, well-built WordPress plugins.** No bloat, no tracking, no external requests unless you turn them on:
just features that do one job well, with a clean admin interface and careful security.

[rotistudio.com](https://rotistudio.com/) · [Plugins on WordPress.org](https://profiles.wordpress.org/rotistudio/#content-plugins)

## How we build

- **WordPress-native:** core APIs and components first, WordPress Coding Standards, PHP 7.4 and up.
- **Privacy first:** no outbound requests or tracking without an explicit opt-in.
- **Accessible:** admin screens built for keyboard use and strong contrast.
- **Translatable:** every plugin is ready for translation.
